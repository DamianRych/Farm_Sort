# Farm Sort

**Play:** https://damianrych.github.io/Farm_Sort/

A color-sort puzzle on the farm. Tap a haystack to pick up the top eggs, tap
another to drop them. Fill a haystack with four eggs of one color and a chick
hatches; sort the whole farm and the rooster crows. 60 puzzles, from a gentle
start to tricky boards with mystery eggs.

Works with touch, mouse or keyboard, in any window shape. The speaker button
(bottom-right) sets the Music and Sounds volume.

This repository only holds the built web version of the game.
